# BioFrame · Enlaces

Página de enlaces de BioFrame (alternativa gratuita a Linktree), publicada con GitHub Pages:
https://organicbrownkid.github.io/bioframe/

## Cambiar un enlace

1. Abre `index.html` en GitHub y pulsa el ícono del lápiz (*Edit this file*).
2. Busca el botón y cambia solo el valor de `href="..."`.
3. Pulsa *Commit changes*. La página se actualiza sola en 1–2 minutos.

WhatsApp usa el formato `https://wa.me/57XXXXXXXXXX`: indicativo de país + número, sin `+`, espacios ni guiones.

## Archivos

- `index.html`: la página completa (estilos incluidos).
- `assets/bg.webp`: fondo de ondas de partículas.
- `assets/logo.webp`, `favicon.png`, `apple-touch-icon.png`, `og-image.png`: logo en sus distintos tamaños.

Íconos: [Bootstrap Icons](https://icons.getbootstrap.com/) (licencia MIT).
